# Add or Remove a Project

This topic tells you how to give a desktop a project folder and how to take it away. A project appears on the desktop as a drive.

## 1 - What a Project Is

A project is a folder on your disk that holds your work, for example the code of an app. When you plug in a project, the agent can read and change its files. The desktop shows the project as a drive with its own letter, for example E:.

Removing a project from the desktop does not delete the folder. The files stay on your disk.

## 2 - Add a Project

To plug in a project, follow the steps below:

1. Open **Explorer**, and then click **Plug in a project...** in the toolbar. The **Browse For Folder** dialog box appears.
2. Select the folder of the project.
3. Click **OK**. The project appears as a drive in the **Computer** window.

You can also click **Plug in a project...** in the **File** menu of **Code**, or right-click an empty place in the project tree of Code.

## 3 - Remove a Project

To remove a project from the desktop, follow the steps below:

1. Right-click the drive of the project in **Explorer** or in the project tree of **Code**.
2. Click **Eject**. A box tells that the folder stays on your disk.
3. Click **Yes**.

Agent7 closes the windows that show files of the project. The chats of the project stay in the list, but their agents cannot read the files until you plug in the project again.

## 4 - Troubleshooting

- **The project is not in the list.** Make sure that you selected a folder, not a file.
- **The drive says that it is not available.** The folder moved or you deleted it. Remove the drive and plug in the project again.
- **A chat cannot read the files.** Make sure that the project is plugged in. See **[The Agent Does Not Start](agent-does-not-start.md)**.
