# Agent7 Help and Support

This is the home page of the manuals of Agent7. Each app has its own manual. Each manual lists every button, input, and menu item of the app and says what it does. Start with the topic that fits your question, or type a word in the search box.

## 1 - How to Use the Manuals

This chapter explains the parts of a manual. Each manual has the same chapters, in the same order.

### The Chapters of a Manual

- **What It Is For** – Tells you what the app does and who uses it.
- **Open It** – Lists the ways to start the app.
- **The Window** – Names each part of the window, from top to bottom.
- **Controls Reference** – Lists each button, input, menu item, and key. Each row gives the name on the screen and what it does.
- **Common Tasks** – Gives numbered steps for the jobs that you do most.
- **Troubleshooting** – Lists problems and their fixes.

### Words Used in the Manuals

- **App** – A program that opens as a window on a desktop.
- **Desktop** – A virtual Windows 7 computer for one or more projects.
- **Drive** – A place for files on a desktop, for example C: or a USB drive.
- **Agent** – A program that writes and changes code for you.

### Get Help in the App

To open the manual of the window that you work in, press F1. Help and Support opens on the topic of that window. If no window has focus, F1 opens the topic **[The Desktop](desktop.md)**.

## 3 - The Apps

This chapter lists the manual of each app. The Start menu lists the same apps.

### Talk and Watch

- **[Chat](chat.md)** – Talk to the agent and follow its work.
- **[Agent window](surface.md)** – A window that the agent draws with A2UI.
- **[Task Manager](agent-manager.md)** – Chats, agent processes, terminals, and context use.
- **[Event Viewer](event-viewer.md)** – The messages between Agent7 and the agent, as they happen.

### Files and Code

- **[Explorer](explorer.md)** – Browse the drives and plug in projects.
- **[Code](code.md)** – View code, review the changes of the agent, and revert them.
- **[Code Review](code-review.md)** – Let an agent review your changes and send its comments to a chat.
- **[Notepad](notepad.md)** – Read and edit plain text files.
- **[WordPad](wordpad.md)** – Read and write markdown documents.
- **[Recycle Bin](recycle-bin.md)** – Restore the changes that you reverted.

### Tools

- **[Terminal](terminal.md)** – Watch the commands that the agent runs.
- **[Browser](browser.md)** – Browse the web together with the agent.
- **[Agent Paint](paint.md)** – Draw, and watch the agent draw.
- **[Sticky Notes](sticky-notes.md)** – Notes on the desktop, shared with the agent.
- **[Snipping Tool](snipping-tool.md)** – Capture part of the screen.

### System

- **[Control Center](control-centre.md)** – Agents, permissions, and appearance.
- **[Help and Support](help.md)** – This app.

## 4 - Need Help?

If a manual does not answer your question, try these steps:

1. Type a word in the **Search Help** box. Help and Support lists each topic that contains the word.
2. Click **Home** to see all topics.
3. Open the manual of the app that you use and read its **Troubleshooting** chapter.
