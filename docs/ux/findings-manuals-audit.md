# Findings: manuals audit

Writing a manual for every app showed these gaps. Each is an input to the UX evaluation and the fix rounds.

## Controls without test ids
- Context and popup menu items in Paint, WordPad, Snipping Tool and Sticky Notes.
- Control Centre:
  - Agents buttons: Add, Edit, Remove and Set as Default.
  - Permission lists, plus Apply and Cancel.
  - The gadgets option.
  - Agent dialog fields.
- Tabs:
  - Task Manager: Chats, Processes, Terminals and Performance.
  - Event Viewer: General and Details.
- Browser: Refresh and Stop.
- Paint: Color 1, Color 2 and the canvas grip.
- Snipping Tool: Cancel, Options, Copy, the snip type arrow and Delay.
- Sticky Notes: the list rows, Color and Plan note.

## Controls that do nothing or are always disabled
- Paint: the Home and View ribbon tabs. There is no Save or Open.
- WordPad: the Home tab.
- Code: New, Save, Save all, Undo and Redo.
- Snipping Tool: Free-form Snip, and Send to chat.

## Missing features
- Notepad: there is no Save As, so a new file cannot be saved. There is no Find or Print.
- Terminal: read only. There is no Clear or Copy.
- Explorer: there is no search, copy, move, delete or rename.
- Browser: one tab only and no bookmarks. The status bar always shows fixed text.

## Help access and consistency
- These apps have no menu bar, so they have no Help entry: Explorer, Terminal, Browser, Event Viewer, Task Manager, Recycle Bin, Snipping Tool, Sticky Notes and Control Centre.
- There is no Help button on the title bar.
- The Welcome dialog cannot be closed.
- On the connection bar, Minimize and Maximize act on the OS window. On an app title bar, they act on the app window.
- The Help topic is not saved when Agent7 restarts.
- F1 does nothing in the Launcher.
